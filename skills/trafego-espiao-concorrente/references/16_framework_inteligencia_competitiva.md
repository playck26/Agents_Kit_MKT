# FRAMEWORK DE INTELIGÊNCIA COMPETITIVA — TRÁFEGO PAGO
## Documento de conhecimento do Agente Espião Concorrente

Este framework cobre: (1) classificação de concorrentes, (2) fontes de análise, (3) critérios por canal, (4) mapa de ofertas, (5) mapa de criativos e ângulos, (6) análise de landing pages, (7) síntese competitiva e (8) recomendações acionáveis.

---

## 1. CLASSIFICAÇÃO DOS PLAYERS

Antes de analisar, classifique cada empresa ou marca.

| Tipo | Definição | Como usar na análise |
|------|-----------|----------------------|
| Concorrente direto | Vende produto/serviço parecido para o mesmo ICP | Comparar oferta, promessa, funil e criativos diretamente |
| Concorrente indireto | Resolve a mesma dor com solução diferente | Identificar objeções e alternativas que disputam atenção/orçamento |
| Referência aspiracional | Não concorre diretamente, mas tem comunicação forte | Extrair padrões adaptáveis, sem copiar literalmente |
| Substituto | Solução improvisada ou alternativa usada pelo ICP | Entender barreiras de compra e argumentos contra inércia |

### Perguntas de validação

- Esse player vende para o mesmo ICP?
- Resolve a mesma dor?
- Disputa o mesmo momento de compra?
- Disputa o mesmo orçamento?
- Está no mesmo país/região?
- Tem ticket ou proposta de valor comparável?

## 2. FONTES DE ANÁLISE

### Fontes principais

- Biblioteca de Anúncios da Meta
- Site institucional
- Landing pages
- Páginas de produto
- Página de preços
- Google SERP e anúncios de busca, quando fornecidos
- Prints e links enviados pelo usuário
- Redes sociais abertas
- Marketplaces, quando for varejo

### Como tratar evidência

Classifique cada achado:

- **Observado:** visível em print, link, anúncio ou página
- **Inferido:** conclusão razoável a partir de evidências visíveis
- **Hipótese:** possibilidade que precisa de confirmação

Exemplo:

- Observado: "A landing usa CTA 'Agendar demonstração'."
- Inferido: "O funil parece focado em lead consultivo."
- Hipótese: "Provavelmente priorizam leads B2B de ticket mais alto."

## 3. ANÁLISE DE META ADS

### O que observar

| Elemento | Perguntas |
|----------|-----------|
| Volume aparente | Há muitos anúncios ativos ou poucas peças? |
| Recência | Existem anúncios recentes ou antigos ainda ativos? |
| Formato | Imagem, vídeo, carrossel, UGC, catálogo, depoimento? |
| Ângulo | Dor, desejo, prova social, comparativo, oferta, demonstração? |
| Hook | O que aparece primeiro para parar o scroll? |
| Copy | Promessa clara, específica ou genérica? |
| CTA | Demo, comprar, WhatsApp, teste grátis, orçamento, cupom? |
| Oferta | Qual entrada está sendo promovida? |
| Prova | Logos, números, reviews, casos, antes/depois? |
| Destino | Landing, produto, WhatsApp, formulário, app, marketplace? |

### Sinais úteis

- Muitos anúncios com a mesma promessa podem indicar ângulo central do mercado.
- Várias versões de um mesmo conceito podem indicar tentativa de otimização criativa.
- Anúncios ativos há muito tempo podem sugerir conceito durável, mas não provam performance.
- Criativos muito parecidos entre concorrentes indicam saturação visual.
- Ausência de oferta clara pode abrir oportunidade para o cliente ser mais direto.

### Red flags competitivas

- Concorrentes usando prova social forte e o cliente sem prova.
- Mercado inteiro oferecendo condição de entrada melhor que o cliente.
- Concorrentes segmentando dores específicas enquanto o cliente fala genericamente.
- Vários players com landing específica por ICP e o cliente mandando tráfego para home.
- Criativos dos concorrentes demonstram produto melhor que os do cliente.

## 4. ANÁLISE DE GOOGLE/SEARCH

### Tipos de intenção

| Intenção | Exemplo | Implicação |
|----------|---------|------------|
| Marca | "[nome da empresa]" | Proteger demanda existente |
| Categoria | "software de CRM" | Disputa direta por solução |
| Dor/problema | "como reduzir abandono de carrinho" | Oportunidade educacional |
| Comparação | "alternativa ao [concorrente]" | Momento forte de decisão |
| Preço | "preço [categoria]" | Usuário sensível a oferta e planos |
| Local | "loja de móveis em Curitiba" | Relevante para varejo físico |

### O que observar

- Promessa no título do anúncio
- Extensões usadas
- Oferta ou condição destacada
- Landing usada para cada intenção
- Concorrentes comprando marca do cliente, se o usuário trouxer evidência
- Uso de comparativos ou alternativas
- Páginas orgânicas fortes que podem influenciar mídia paga

### Implicações para campanha

- Se há muita demanda de marca, separar Search Marca.
- Se há busca de comparação, considerar campanha/landing comparativa.
- Se concorrentes dominam termos de categoria, trabalhar diferenciação na copy.
- Se intenção é educacional, Meta/YouTube/conteúdo podem alimentar busca futura.

## 5. MAPA DE OFERTAS

Para cada concorrente, identifique a oferta de entrada.

| Tipo de oferta | Exemplos | Quando é forte |
|----------------|----------|----------------|
| Demo/diagnóstico | "Agende uma demonstração" | SaaS B2B, venda consultiva |
| Trial gratuito | "Teste grátis por 7/14 dias" | Produto self-service |
| Desconto direto | "20% off" | Varejo, sazonalidade, estoque |
| Frete/condição | "Frete grátis acima de R$X" | E-commerce |
| Lead magnet | Ebook, checklist, webinar | Topo/meio de funil tech |
| Bundle/kit | Compre junto, kit promocional | Varejo com margem e mix |
| Garantia | Satisfação, troca fácil, garantia estendida | Redução de risco |
| Comparativo | "Troque planilhas por..." | Tecnologia e soluções substitutas |

### Perguntas para avaliar força da oferta

- A oferta é clara em 3 segundos?
- Ela reduz risco?
- Ela cria urgência real?
- Ela conversa com a dor principal do ICP?
- Ela é melhor, igual ou pior que a do cliente?
- Existe prova suficiente para sustentar a promessa?

## 6. MAPA DE ÂNGULOS CRIATIVOS

### Tecnologia

| Ângulo | Sinal nos concorrentes | Oportunidade |
|--------|------------------------|--------------|
| Dor → Solução | Começa pelo problema operacional do ICP | Criar variações por dor específica |
| Demonstração de produto | Prints, dashboards, fluxo de uso | Mostrar produto em contexto real |
| Prova social | Logos, cases, números | Fortalecer confiança e reduzir risco |
| Comparativo | Vs planilha, método antigo, concorrente | Capturar usuários em troca de solução |
| Autoridade | Fundador, especialista, certificações | Ganhar confiança em ticket alto |
| Educacional | Conteúdo que ensina antes de vender | Alimentar topo e remarketing |
| Trial/Demo | Entrada de baixo risco | Melhorar conversão inicial |

### Varejo

| Ângulo | Sinal nos concorrentes | Oportunidade |
|--------|------------------------|--------------|
| Produto em destaque | Produto isolado, preço, benefício | Melhorar clareza de compra |
| Lifestyle | Produto em uso, contexto aspiracional | Aumentar desejo |
| UGC/cliente real | Depoimentos, reviews, fotos reais | Criar prova social visual |
| Promoção | Desconto, cupom, preço âncora | Competir em conversão direta |
| Frete/condição | Frete grátis, troca fácil | Reduzir fricção |
| Escassez | Últimas unidades, coleção limitada | Acelerar decisão |
| Sazonalidade | Datas comerciais e campanhas temáticas | Planejar calendário promocional |

### Como avaliar saturação

Um ângulo está saturado quando:

- Muitos concorrentes usam a mesma promessa
- Criativos têm aparência muito parecida
- A oferta virou commodity
- Não há diferenciação clara além de preço/desconto

Um ângulo está aberto quando:

- Poucos concorrentes exploram uma dor relevante
- Existe objeção importante sem resposta
- O cliente tem prova ou diferencial que os outros não mostram
- O mercado fala genericamente e o cliente pode ser específico

## 7. ANÁLISE DE LANDING PAGE

### Acima da dobra

Avalie:

- Headline principal
- Subheadline
- CTA
- Prova imediata
- Imagem ou demonstração
- Clareza da oferta
- Compatibilidade com anúncio

### Estrutura da página

| Bloco | O que procurar |
|-------|----------------|
| Proposta de valor | Promessa clara e específica |
| Problema | Dor do ICP nomeada com precisão |
| Solução | Como o produto/serviço resolve |
| Prova | Logos, depoimentos, reviews, números |
| Oferta | Demo, trial, desconto, frete, garantia |
| Objeções | Preço, tempo, risco, implementação, troca |
| CTA | Frequência, clareza e consistência |
| Fricção | Formulário longo, carregamento, navegação confusa |

### Sinais competitivos fortes

- Landing específica por segmento ou caso de uso.
- Prova social logo no primeiro viewport.
- CTA único e repetido ao longo da página.
- Demonstração do produto em vez de imagem genérica.
- Oferta alinhada com o anúncio.

|--------|------|------------------|------------------|--------------------|---------------|-----|-----------------|

### Critérios de força percebida

Classifique como:

- **Alta:** oferta clara, prova forte, criativos consistentes, landing alinhada
- **Média:** boa comunicação, mas com lacunas de prova, CTA ou especificidade
- **Baixa:** mensagem genérica, pouca prova, oferta fraca ou funil confuso

Essa classificação é qualitativa. Não significa performance real.

## 9. GAPS E OPORTUNIDADES

### Tipos de oportunidade

| Tipo | Exemplo |
|------|---------|
| Oferta | Concorrentes não usam garantia; cliente pode usar |
| Criativo | Mercado usa estático genérico; cliente pode usar demonstração/UGC |
| Prova | Poucos mostram números reais; cliente tem cases fortes |
| Segmento | Todos falam amplo; cliente pode focar em ICP específico |
| Landing | Concorrentes mandam para home; cliente pode criar landing dedicada |
| Busca | Ninguém explora termos de comparação; cliente pode testar |
| Sazonalidade | Mercado não antecipa data comercial; cliente pode chegar antes |

### Como priorizar

Priorize oportunidades por:

1. Impacto potencial
2. Facilidade de execução
3. Alinhamento com Dossiê
4. Evidência competitiva
5. Urgência comercial

## 10. RISCOS COMPETITIVOS

Riscos comuns:

- Cliente tem oferta mais fraca que o padrão do mercado.
- Concorrentes têm prova social mais forte.
- Cliente depende de preço enquanto concorrentes vendem valor.
- Mercado já saturou um ângulo que o cliente quer testar.
- Landing do cliente é mais genérica que as páginas concorrentes.
- Concorrentes educam melhor o comprador antes da conversão.
- A promessa do cliente é parecida demais com todos os outros.

Para cada risco, indique mitigação:

- Melhorar oferta
- Criar prova
- Mudar ângulo
- Segmentar ICP
- Ajustar landing
- Testar comparativo
- Reposicionar mensagem

## 11. RECOMENDAÇÕES ACIONÁVEIS

Toda recomendação deve ter:

- O que fazer
- Por que faz sentido
- Onde aplicar
- Prioridade
- Próximo agente mais adequado

Exemplo:

| Recomendação | Por quê | Onde aplicar | Prioridade |
|--------------|---------|--------------|------------|
| Criar criativos de demonstração do produto | Concorrentes usam prova visual e cliente ainda fala genérico | Meta Ads / Landing | Alta |

## 12. LIMITAÇÕES E ÉTICA

Não afirmar:

- Orçamento do concorrente
- CPA, CAC, ROAS ou lucro do concorrente
- Público exato usado
- Estratégia interna
- Resultados reais
- Dados privados

Pode afirmar:

- O que está visível
- O que parece provável com base em evidência
- Quais hipóteses valem teste
- Como adaptar padrões ao cliente
